# IP Guard

فایروال لیست سفید برای سرورهای لینوکس، با منوی تعاملی در ترمینال و ربات تلگرام.

وقتی فایروال روشن است، **فقط** IPهای لیست سفید و (در صورت تمایل) IPهای کلادفلر می‌توانند به سرور وصل شوند و بقیه‌ی IPها بلاک می‌شوند. مناسب سرورهایی که پشت CDN کلادفلر هستند یا فقط از چند سرور ریلی ترافیک می‌گیرند و می‌خواهید جلوی اسکن و حمله‌ی مستقیم گرفته شود.

- یک فایل پایتون، بدون هیچ کتابخانه‌ی اضافه
- جدول nftables مستقل (`inet ip_guard`)؛ با پنل‌هایی مثل Hiddify و x-ui تداخل ندارد و ری‌استارت پنل آن را پاک نمی‌کند
- تایمر ایمنی: بعد از روشن کردن باید تایید کنید، وگرنه فایروال خودش خاموش می‌شود تا هیچ‌وقت پشت در نمانید
- ربات تلگرام با داشبورد سرور، آمار بلاک، مدیریت لیست سفید و گزارش همه‌ی تغییرات

## چطور کار می‌کند

وقتی فایروال **روشن** و حالت روی **ALL** است، یک اتصال جدید فقط در این حالت‌ها قبول می‌شود:

| منبع | دسترسی |
|---|---|
| IPهای فعال لیست سفید | همه‌ی پورت‌ها (شامل SSH) |
| رنج‌های کلادفلر (اگر مجاز باشد) | همه‌ی پورت‌ها به جز SSH |
| هر IP، فقط وقتی SSH «باز» است | فقط پورت SSH |
| بقیه | **بلاک** (و در آمار شمرده می‌شود) |

- پاسخ اتصال‌هایی که خود سرور باز کرده همیشه آزاد است؛ یعنی ترافیک خروجی (آپدیت، ربات تلگرام، تانل‌هایی که از این سرور شروع می‌شوند) قطع نمی‌شود.
- پیام‌های کنترلی IPv6 و پاسخ‌های DHCP همیشه آزادند تا شبکه‌ی سرور از کار نیفتد.
- وقتی فایروال **خاموش** است، جدول کلاً حذف می‌شود و همه می‌توانند وصل شوند.

حالت دوم، **LISTED PORTS**، فقط پورت‌هایی را که خودتان مشخص کنید محدود می‌کند و بقیه‌ی پورت‌ها باز می‌مانند.

## پیش‌نیازها

- لینوکس با systemd (تست‌شده روی Ubuntu 24.04)
- دسترسی root
- Python 3.8 یا جدیدتر (در اوبونتو از قبل نصب است)
- nftables

بررسی:

```bash
python3 --version
nft --version
```

اگر nft نصب نبود:

```bash
apt update && apt install -y nftables
```

## نصب

**۱.** فایل `ip_guard.py` را در پوشه‌ی `/root` سرور قرار دهید (مثلاً با WinSCP، FileZilla یا `scp`).

**۲.** منو را اجرا کنید:

```bash
python3 /root/ip_guard.py
```

**۳.** از منوی اصلی `8` (Settings) و بعد `3` (Install / update) را بزنید.
این کار:
- اسکریپت را در `/opt/ip-guard/ip_guard.py` کپی می‌کند
- سرویس `ip-guard.service` را فعال می‌کند تا فایروال بعد از ری‌بوت دوباره اعمال شود
- IP فعلی SSH شما را به لیست سفید اضافه می‌کند

> بعد از نصب، فایروال هنوز **خاموش** است. تا خودتان روشنش نکنید چیزی بلاک نمی‌شود.

## راه‌اندازی اولیه (مرحله به مرحله)

### مرحله ۱: لیست سفید

منوی `2` (Whitelist):

- `1` Add: یک IP یا رنج اضافه کنید، برچسب اختیاری است (مثلاً `relay-1`)
- `2` Paste a list: چند IP را یکجا بچسبانید، هر کدام در یک خط، برچسب بعد از فاصله:

```
1.2.3.4 relay-1
5.6.7.8 relay-2
10.20.30.0/24 office
```

با یک خط خالی تمام می‌شود.

چه چیزهایی را اضافه کنید:
- سرورهای ریلی/تانل که به این سرور وصل می‌شوند
- IP خودتان (اگر ثابت است)
- هر سرور دیگری که باید به این سرور دسترسی داشته باشد (مانیتورینگ، بکاپ و...)

فرمت‌های قابل قبول: `1.2.3.4` ، `1.2.3.0/24` ، `2001:db8::1` ، `2001:db8::/48`
رنج‌های خیلی بزرگ (بزرگ‌تر از `/8` در IPv4 و `/16` در IPv6) پذیرفته نمی‌شوند.

### مرحله ۲: رنج‌های کلادفلر

منوی `5` (Cloudflare) و بعد `1` (Update ranges now).

اگر کانفیگ‌هایتان پشت CDN کلادفلر است، کلادفلر باید **allowed** بماند؛ وگرنه با روشن شدن فایروال همه‌ی کانفیگ‌های CDN قطع می‌شوند. اگر از کلادفلر استفاده نمی‌کنید، با `2` آن را غیرمجاز کنید.

### مرحله ۳: حالت بلاک

منوی `3` (Block mode). حالت پیش‌فرض **ALL** است و برای بیشتر سرورها همین مناسب است.

در همین منو با `2` مشخص می‌کنید پینگ برای همه آزاد باشد یا فقط برای لیست سفید.

### مرحله ۴: SSH

منوی `4` (SSH access):
- `1` Open to everyone: همه می‌توانند به پورت SSH وصل شوند
- `2` Whitelist only: فقط لیست سفید (امن‌تر). IP فعلی شما قبل از بستن خودکار به لیست اضافه می‌شود

اگر SSH روی پورتی غیر از 22 است، اول از منوی `8` → `2` شماره‌ی پورت را تنظیم کنید.

### مرحله ۵: روشن کردن فایروال

منوی `1` (Firewall) → `1` (Switch ON) → `y`

از این لحظه تایمر ایمنی شروع می‌شود (پیش‌فرض ۲۰ دقیقه) و بالای همه‌ی صفحه‌ها نوشته می‌شود `Confirm pending`.

### مرحله ۶: تست

در این فاصله تست کنید:
- کانفیگ‌های کلادفلر وصل می‌شوند
- ریلی‌ها/تانل‌ها کار می‌کنند
- از یک IP خارج از لیست (مثلاً اینترنت موبایل) سرور **در دسترس نیست**

> با IP خودتان تست نکنید؛ IP خودتان در لیست سفید است و بلاک نمی‌شود.

### مرحله ۷: تایید

اگر همه‌چیز درست بود: منوی `1` (Firewall) → `2` (Confirm).
اگر مشکلی بود، کاری نکنید؛ بعد از پایان تایمر فایروال خودش خاموش می‌شود. یا با `1` خودتان خاموشش کنید.

## راه‌اندازی ربات تلگرام

**۱.** در تلگرام به [@BotFather](https://t.me/BotFather) بروید، `/newbot` را بفرستید، یک نام و یک یوزرنیم که به `bot` ختم شود انتخاب کنید. توکنی مثل این می‌گیرید:

```
123456789:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

> برای این کار حتماً یک **ربات جدید** بسازید. توکن ربات دیگری (مثلاً ربات پنل) را استفاده نکنید.

**۲.** در منو: `6` (Telegram bot) → `1` (Set token) و توکن را وارد کنید.

**۳.** شناسه‌ی عددی خودتان را بگیرید: به [@userinfobot](https://t.me/userinfobot) بروید و Start بزنید؛ عدد `Id` را کپی کنید.

**۴.** در منو: `2` (Add admin) و شناسه را وارد کنید. فقط ادمین‌ها جواب می‌گیرند و پیام بقیه نادیده گرفته می‌شود. می‌توانید چند ادمین اضافه کنید.

**۵.** ربات جدیدتان را در تلگرام باز کنید و یک بار Start بزنید (ربات نمی‌تواند اول به شما پیام بدهد).

**۶.** در منو: `4` (Start / restart) و بعد `5` (Test connection). اگر پیام تست به تلگرامتان رسید، همه‌چیز آماده است.

**۷.** در تلگرام به ربات `/start` بفرستید.

### امکانات ربات

- **داشبورد:** IPv4 و IPv6 سرور، آپتایم، CPU، RAM، دیسک، وضعیت فایروال و SSH، تعداد بلاک‌ها و زمان باقی‌مانده تا تایید
- **لیست سفید:** صفحه‌بندی‌شده؛ روی هر مورد بزنید تا فعال/غیرفعال، تغییر برچسب یا حذف کنید
- **افزودن IP با پیام:** IP یا لیست IP را مستقیم در چت بفرستید؛ ربات پیش‌نمایش نشان می‌دهد (تکراری و نامعتبرها را جدا می‌کند) و با دکمه‌ی تایید اضافه می‌کند
- **فایروال:** روشن، خاموش، تایید
- **SSH:** باز یا بسته کردن (مثلاً وقتی از یک IP جدید باید وارد شوید)
- **کلادفلر:** آپدیت رنج‌ها
- **آمار بلاک:** تعداد کل بسته‌های بلاک‌شده، تلاش‌های SSH و پربلاک‌ترین IPها؛ اگر یکی از آن‌ها سرور خودتان است، با یک دکمه مجازش کنید
- **رویدادها:** ۱۵ تغییر آخر با زمان و انجام‌دهنده
- **گزارش تغییرات:** هر تغییر (از ترمینال یا ربات) به همه‌ی ادمین‌ها اطلاع داده می‌شود

### دستورهای ربات

| دستور | کار |
|---|---|
| `/start` | داشبورد |
| `/ip` | آی‌پی سرور |
| `/wl` | لیست سفید |
| `/stats` | آمار بلاک |
| `/add` | افزودن IP (یا مستقیم: `/add 1.2.3.4, 5.6.7.8`) |
| `/help` | راهنما |

## راهنمای منوها

| منو | کار |
|---|---|
| `1` Firewall | روشن / خاموش / تایید |
| `2` Whitelist | افزودن، چسباندن لیست، فعال/غیرفعال، تغییر برچسب، حذف |
| `3` Block mode | حالت ALL یا LISTED PORTS، پینگ، افزودن/حذف پورت |
| `4` SSH access | باز برای همه یا فقط لیست سفید |
| `5` Cloudflare | آپدیت رنج‌ها، مجاز/غیرمجاز |
| `6` Telegram bot | توکن، ادمین‌ها، شروع/توقف سرویس، تست، راهنما |
| `7` Statistics | آمار بلاک، مجاز کردن یک IP از لیست، صفر کردن آمار |
| `8` Settings | زمان تایمر ایمنی، پورت SSH، نصب/به‌روزرسانی |
| `9` Help | راهنمای کامل داخل برنامه |

صفحه‌ی اصلی اطلاعات سرور (IPها، آپتایم، CPU/RAM و تعداد بلاک‌ها) را نشان می‌دهد و بالای هر صفحه یک نوار وضعیت ثابت هست.

## تایمر ایمنی

- بعد از روشن کردن فایروال، باید در زمان مشخص‌شده (پیش‌فرض ۲۰ دقیقه) «Confirm» را بزنید؛ از ترمینال یا ربات.
- اگر تایید نکنید، فایروال خودش خاموش می‌شود و به ادمین‌های ربات پیام می‌رود.
- اگر سرور قبل از تایید ری‌بوت شود، بعد از بالا آمدن فایروال خاموش می‌ماند.
- زمان تایمر را از منوی `8` → `1` تغییر دهید (۱ تا ۲۴۰ دقیقه).

## دستورهای خط فرمان

```bash
python3 /opt/ip-guard/ip_guard.py            # منوی تعاملی
python3 /opt/ip-guard/ip_guard.py status     # وضعیت خلاصه
python3 /opt/ip-guard/ip_guard.py confirm    # تایید فایروال
python3 /opt/ip-guard/ip_guard.py rollback   # خاموش کردن فوری فایروال
python3 /opt/ip-guard/ip_guard.py apply      # اعمال دوباره‌ی تنظیمات ذخیره‌شده
```

### فایل‌ها

| مسیر | محتوا |
|---|---|
| `/etc/ip-guard/config.json` | تنظیمات، لیست سفید، توکن ربات |
| `/var/lib/ip-guard/` | وضعیت تایمر، آمار، رویدادها |
| `/opt/ip-guard/ip_guard.py` | نسخه‌ی نصب‌شده که سرویس‌ها اجرا می‌کنند |
| `ip-guard.service` | اعمال فایروال هنگام بوت |
| `ip-guard-bot.service` | ربات تلگرام |

> فایل `config.json` شامل توکن ربات است؛ آن را جایی منتشر نکنید.

## به‌روزرسانی

1. فایل جدید را جای `/root/ip_guard.py` قرار دهید.
2. `python3 /root/ip_guard.py` را اجرا کنید.
3. اگر بالای صفحه `Confirm pending` نوشته شده، اول از منوی `1` تایید کنید.
4. منوی `8` → `3` (Install / update). ربات خودکار ری‌استارت می‌شود.
5. برای بارگذاری قوانین جدید:

```bash
python3 /root/ip_guard.py apply
```

تنظیمات و لیست سفید شما حفظ می‌شود. اگر نسخه‌ی نصب‌شده قدیمی‌تر از فایل باشد، منو هشدار می‌دهد.

## عیب‌یابی و حالت اضطراری

**خاموش کردن فوری فایروال** (مثلاً از کنسول وب دیتاسنتر):

```bash
python3 /opt/ip-guard/ip_guard.py rollback
```

یا مستقیم:

```bash
nft delete table inet ip_guard
```

**دیدن قوانین فعال:**

```bash
nft list chain inet ip_guard input
```

**ربات جواب نمی‌دهد:**

```bash
systemctl status ip-guard-bot.service --no-pager
journalctl -u ip-guard-bot.service -n 30 --no-pager
```

- توکن درست است؟ (منوی `6` → `5`)
- شناسه‌ی شما در لیست ادمین‌هاست؟
- در ربات Start زده‌اید؟
- سرور به `api.telegram.org` دسترسی دارد؟

**چیزی بلاک نمی‌شود:**
- فایروال روشن است؟ (`status`)
- حالت روی ALL است؟ حالت LISTED PORTS بدون پورت، چیزی را بلاک نمی‌کند
- از IP خارج از لیست سفید تست می‌کنید؟

**کانفیگ‌های کلادفلر قطع شده‌اند:**
- کلادفلر در منوی `5` روی allowed است؟
- رنج‌ها آپدیت شده‌اند؟ (تعداد رنج نباید صفر باشد)

## حذف کامل

```bash
systemctl disable --now ip-guard-bot.service ip-guard.service
nft delete table inet ip_guard
rm -rf /opt/ip-guard /etc/ip-guard /var/lib/ip-guard
rm -f /etc/systemd/system/ip-guard.service /etc/systemd/system/ip-guard-bot.service
systemctl daemon-reload
```
