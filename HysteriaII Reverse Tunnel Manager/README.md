# hysteria-tm

ابزار منوی تعاملی برای ساخت و مدیریت تانل‌های **Hysteria 2** بین یک سرور **ایران** و یک سرور **خارج**.

اسکریپت روی سرور ایران، با دسترسی root اجرا می‌شود و از طریق SSH به سرور خارج وصل می‌شود. همه‌چیز، از ساخت گواهی و کانفیگ تا ساخت سرویس‌های systemd و تست تانل، از همین منو انجام می‌شود.

## قابلیت‌ها

- ساخت تانل **direct**: سرور Hysteria روی خارج، کلاینت روی ایران
- ساخت تانل **reverse**: سرور Hysteria روی ایران به‌همراه rbridge، کلاینت روی خارج (وقتی خارج فقط به ایران دسترسی دارد)
- ساخت تانل **both**: ترکیب direct و reverse پشت haproxy روی ایران
- سه پروفایل آماده: `stealth-hop`، `tcp-lite`، `max-stealth`
- بنچمارک خودکار که هر ۶ ترکیب را تست و امتیاز می‌دهد
- نصب آفلاین Hysteria و rbridge وقتی سرور به اینترنت دسترسی ندارد
- مدیریت تانل‌ها: وضعیت، شروع، توقف، ری‌استارت و حذف
- چند فوروارد پورت برای هر تانل: نمایش جدول «کدام پورت ایران به کدام پورت خارج می‌رود»، اضافه، بازنویسی و حذف
- ذخیرهٔ IP ایران و آدرس/پورت/کاربر SSH خارج در `config-hysteria-tm.json` (رمز هرگز ذخیره نمی‌شود)

## پیش‌نیازها

- سرور ایران با Ubuntu و دسترسی root
- سرور خارج با SSH و systemd
- برای پروفایل `max-stealth`: یک دامنه که رکورد A آن به سرور مربوطه اشاره کند

## نصب سریع

پکیج رسمی:
روی سرور ایران، با root:

```bash
curl -fL -o hysteria-tm.tar.gz "https://github.com/URT19/MyLinuxTools/raw/refs/heads/main/HysteriaII%20Reverse%20Tunnel%20Manager/hysteria-tm-0.9.2.tar.gz"
tar -xzf hysteria-tm.tar.gz
cd hysteria-tm
sudo python3 ./hysteria-tm
```

**مهم:** حتماً اول `cd hysteria-tm` را بزن. اگر از پوشهٔ `/root` اجرا کنی، پایتون پوشه را به‌جای فایل می‌گیرد و خطای `can't find '__main__' module` می‌دهد. بهتر است قبل از اجرا با `tmux` یا `screen` کار کنی تا اگر SSH قطع شد، نصب یا بنچمارک ادامه پیدا کند.

پکیج شامل Hysteria v2.13.0، `install_server.sh` و rbridge است، پس روی سرورهایی که به GitHub یا `get.hy2.sh` دسترسی ندارند هم نصب می‌شود.


## قبل از اجرای هر تانل، اول از گزینه 6 تست بنچمارک بگیرید، ببینید کدوم تانل ها براتون جواب میده

## مثال‌های کاربردی

### ۱. ساخت یک تانل ساده (stealth-hop)

1. منوی **1) Create a new tunnel** را بزن.
2. نام تانل را بنویس، مثلاً `tehran1`.
3. از منوی **Tunnel preset** گزینهٔ **1** (direct + stealth-hop) را انتخاب کن.
4. IP سرور ایران و IP سرور خارج، و RAM را بده.
5. پورت TCP که سرویس تو روی خارج به آن گوش می‌دهد را بده، مثلاً `443`.
6. پورت عمومی روی ایران را بده؛ کاربرها به این پورت وصل می‌شوند.

### ۲. تانل reverse با پروفایل tcp-lite

همان مراحل بالا، ولی گزینهٔ **4) reverse + tcp-lite** را از منوی preset انتخاب کن.

### ۳. تانل max-stealth با دامنه

1. پروفایل **max-stealth** را انتخاب کن (گزینهٔ 5 یا 6 در منوی preset).
2. دامنه‌ای بده که رکورد A آن به سرور مربوطه اشاره کند.
3. ایمیل برای حساب ACME را بده (پیش‌فرض: `admin@<دامنه>`).
4. یک نام ECH عمومی (decoy) بده که شبیه یک سایت معروف باشد؛ نباید دامنهٔ خودت باشد.

اگر گواهی معتبری برای آن دامنه روی سرور پیدا شود، اسکریپت پیشنهاد می‌دهد از همان استفاده کنی.

### ۴. اجرای بنچمارک

1. منوی **6) Auto benchmark** را بزن.
2. با `y` شروع کن.
3. چک‌لیست وابستگی‌ها نشان داده می‌شود. تا وقتی همهٔ موارد ✔ نشوند، تست شروع نمی‌شود.
4. دامنه‌ها، ایمیل و IP را بده.
5. در پایان جدول نتیجه و علت شکست تست‌ها نشان داده می‌شود. نتیجهٔ کامل در `/etc/tunnel-manager/bench/` ذخیره می‌شود.

### ۵. نصب آفلاین

پکیج رسمی از قبل پوشه `hysteria-tm-files` را دارد که این سه فایل داخلش است:

```
hysteria-tm-files/hysteria-linux-amd64
hysteria-tm-files/install_server.sh
hysteria-tm-files/rbridge-linux-x86_64
```

اسکریپت خودش این فایل‌ها را پیدا می‌کند و قبل از نصب آنلاین پیشنهاد می‌دهد از آن‌ها استفاده کنی. اگر بخواهی نسخهٔ دیگری از یک فایل را به‌جای آن بگذاری، همان فایل را با همان نام داخل این پوشه جایگزین کن.

### ۶. مدیریت یک تانل

منوی **2) Manage tunnels** را بزن، تانل را انتخاب کن و بعد یکی از این کارها را انجام بده: وضعیت، شروع، توقف، ری‌استارت، تغییر وزن haproxy (فقط برای both)، یا حذف.
