# آموزش کامل بکاپ گرفتن و بازگردانی سرور Hetzner

### این اسکریپت برای گرفتن بکاپ از سرورهای هتزنر و دانلود به سرور یا سیستم دلخواه شخصی طراحی شده است.


این آموزش مراحل کار را از ابتدا تا انتها توضیح می‌دهد.

---

## ۱. پیش‌نیازها

روی سیستمی که اسکریپت را از آن اجرا می‌کنید، باید این ابزارها باشند:

```
ssh
ssh-keygen
gzip
sha256sum
rsync
```

اگر یکی از آن‌ها نبود، اسکریپت نصب را پیشنهاد می‌دهد.

⚠️ اسکریپت را روی سروری اجرا نکنید که قرار است از آن بکاپ بگیرید یا روی آن ریستور کنید.

اگر می‌خواهید فایل را با IDM دانلود کنید، روی ویندوز هم به PowerShell نیاز دارید. این ابزار در ویندوز معمولاً از قبل نصب است.

---

## ۲. آماده‌سازی در پنل Hetzner

### مرحله ۲-۱: گرفتن اسنپ‌شات

۱. وارد پنل Hetzner Cloud شوید.
۲. سرور اصلی را باز کنید.
۳. از بخش
Snapshots
یک اسنپ‌شات بگیرید.

### مرحله ۲-۲: ساخت سرور موقت از روی اسنپ‌شات

۱. یک سرور جدید بسازید.
۲. در بخش Image، گزینه
Snapshot
را انتخاب کنید و اسنپ‌شات خودتان را بزنید.
۳. نوع سرور را مثل سرور اصلی یا بزرگ‌تر انتخاب کنید.

### مرحله ۲-۳: فعال کردن Rescue

۱. سرور موقت را باز کنید.
۲. به تب
Rescue
بروید.
۳. کلید SSH خودتان را انتخاب کنید.
۴. روی
Enable Rescue System
بزنید.
۵. به تب
Power
بروید و
Reboot
را بزنید.
۶. چند دقیقه صبر کنید.

### مرحله ۲-۴: ورود به Rescue با password

اگر کلید SSH انتخاب نکرده باشید، Hetzner یک password به ایمیل شما می‌فرستد.

۱. با SSH یک بار وارد شوید.
۲. اگر خواست password را عوض کنید، همان‌جا عوض کنید.
۳. بعد از این، اسکریپت را با گزینه
password
اجرا کنید.

---

## ۳. ساخت کلید SSH (اگر ندارید)

اسکریپت خودش کلید را می‌سازد. اگر بخواهید دستی بسازید، این دستور را بزنید:

```bash
ssh-keygen -t ed25519 -C "hetzner-backup"
```

کلید عمومی را این‌طور ببینید:

```bash
cat ~/.ssh/id_ed25519.pub
```

خروجی را در پنل Hetzner بگذارید:

۱. به
Security
بروید.
۲. روی
SSH Keys
بزنید.
۳. روی
Add SSH Key
بزنید و خروجی را در
Public Key
بچسبانید.

⚠️ فقط فایل `.pub` را جایی بدهید. فایل بدون `.pub` کلید خصوصی است و نباید منتشر شود.

## ۴. اجرای اسکریپت

```bash
chmod +x hetzner_backup.sh
./hetzner_backup.sh
```

منو این شکلی است:

```
1) Backup kamel
2) Restore
3) Entegal fayl backup be server digar
0) Khorooj
```

اسکریپت در هر مرحله منتظر `y` یا `n` می‌ماند. اگر کلید دیگری بزنید، بسته نمی‌شود و دوباره می‌پرسد.

## ۵. بکاپ گرفتن (گزینه ۱)

۱. ابتدا توضیحات را بخوانید و
y
بزنید.
۲. روش اتصال را انتخاب کنید:
۱ برای کلید SSH
یا
۲ برای password
۳. IP سرور موقت (Rescue) را وارد کنید.
۴. نام disk را بزنید. پیش‌فرض
sda
است.
۵. اسم فایل را بزنید یا Enter بزنید.
۶. برای شروع dump،
y
بزنید.

dump ممکن است چند ساعت طول بکشد. فایل در مسیر زیر ساخته می‌شود:

```
~/hetzner_backups/
```

### بررسی سلامت فایل

این مرحله چند دقیقه طول می‌کشد. اگر اتصال قطع شد، با دستور زیر دوباره بررسی کنید:

```bash
gzip -t ~/hetzner_backups/NAME.img.gz && echo OK
```

به جای
NAME
نام فایل خودتان را بگذارید.

برای جلوگیری از قطع شدن، داخل
tmux
اجرا کنید:

```bash
tmux new -s check
gzip -t ~/hetzner_backups/NAME.img.gz && echo OK
tmux attach -t check
```

### بقیه مراحل

۱. اگر خواستید، یک
dump
دوم بگیرید تا دو فایل مقایسه شوند.
۲. اگر خواستید، فایل را با
AES-256
رمزگذاری کنید. رمز را جای امن نگه دارید.
۳. اگر خواستید، فایل را به part ها تقسیم کنید.

بعد از پایان، در پنل Hetzner
Rescue
را
Disable
کنید یا سرور موقت را پاک کنید. دیگر کاری به سرور ندارید.

## ۶. تقسیم فایل به part (مثل WinRAR)

اگر فایل بزرگ است و می‌خواهید با IDM دانلود کنید، آن را به part ها تقسیم کنید.

۱. در پایان بکاپ، وقتی پرسید،
y
بزنید.
۲. اندازه part را وارد کنید، مثلاً
500M
یا
1G
یا
2G
.
۳. اسکریپت این فایل‌ها را می‌سازد:

```
server-xxxx.img.gz.part00
server-xxxx.img.gz.part01
...
server-xxxx.img.gz.full.sha256
server-xxxx.img.gz.parts.sha256
```

۴. اگر خواستید، فایل کامل را حذف کنید. اگر فضا دارید، نگه دارید.

### دستی تقسیم کردن (روی سرور لینوکسی)

```bash
cd /root/backups
split -b 1G -d -a 2 server-xxxx.img.gz server-xxxx.img.gz.part
```

## ۷. دانلود با IDM

IDM فقط با
HTTP
یا
FTP
کار می‌کند. پس روی سرور یک سرور موقت HTTP بالا می‌آوریم.

⚠️ قبل از شروع، IP خودتان را پیدا کنید. از سایتی مثل
whatismyip.com
استفاده کنید.

### روی سرور

۱. فقط IP خودتان را به پورت
8000
راه دهید:

```bash
sudo ufw allow from IP_SHOMA to any port 8000 proto tcp
```

۲. یک پوشه با لینک فایل بسازید:

```bash
mkdir -p /root/share
ln -sf /root/backups/NAME.img.gz.part00 /root/share/
```

۳. سرور HTTP را بالا بیاورید:

```bash
cd /root/share
python3 -m http.server 8000 --bind 0.0.0.0
```

### روی ویندوز

۱. در IDM آدرس زیر را اضافه کنید و دانلود کنید:

```
http://IP_SERVER:8000/NAME.img.gz.part00
```

۲. بعد از دانلود، hash را بررسی کنید:

```powershell
Get-FileHash .\NAME.img.gz.part00 -Algorithm SHA256
```

### بعد از دانلود (روی سرور)

۱. سرور HTTP را با
Ctrl + C
ببندید.
۲. دسترسی را ببندید:

```bash
sudo ufw delete allow from IP_SHOMA to any port 8000 proto tcp
rm -rf /root/share
```

---

## ۸. به هم وصل کردن part ها

### در ویندوز با دستور

```powershell
cmd /c copy /b NAME.img.gz.part00 + NAME.img.gz.part01 NAME.img.gz
```

### در ویندوز با 7-Zip

۱. روی اولین part راست‌کلیک کنید.
۲. گزینه
Combine files
را بزنید.

### در لینوکس

```bash
cat NAME.img.gz.part* > NAME.img.gz
```

بعد از وصل کردن، hash فایل کامل را با
full.sha256
مقایسه کنید.

## ۹. ریستور (گزینه ۲)

۱. سرور مقصد را در پنل
Rescue
کنید.
۲. اسکریپت را اجرا کنید و گزینه
2
را بزنید.
۳. هر part یا اسم فایل را وارد کنید. اسکریپت همه part ها را خودش پیدا می‌کند.
۴. IP سرور مقصد را وارد کنید.
۵. اسم disk را بزنید. پیش‌فرض
sda
است.
۶. برای تأیید، کلمه
YES
را با حروف بزرگ بنویسید.

⚠️ همه داده‌های disk مقصد پاک می‌شود.

بعد از پایان ریستور:

۱. در پنل
Rescue
را
Disable
کنید.
۲. سرور را
Reboot
کنید.

اگر سرور بالا نیامد، GRUB را در Rescue دوباره نصب کنید.

## ۱۰. انتقال به سرور دیگر (گزینه ۳)

۱. گزینه
3
را بزنید.
۲. فایل یا یکی از part ها را انتخاب کنید.
۳. IP، پورت SSH، user و مسیر مقصد را وارد کنید.
۴. با
rsync
فایل‌ها فرستاده می‌شوند.
۵. اگر قطع شد، دوباره همان گزینه را بزنید. از جایی که مانده ادامه می‌دهد.
۶. اسکریپت hash را روی سرور مقصد بررسی می‌کند.

---

## ۱۱. نکات امنیتی

- بکاپ شامل کلیدها، password ها و اطلاعات کاربران است.
- قبل از ذخیره در جای عمومی یا ابری، رمزگذاری کنید.
- فایل بکاپ یا `.sha256` را در Git نگذارید.
- بعد از کار، دسترسی‌های موقت فایروال را ببندید.
- سرور موقت و اسنپ‌شات را پاک کنید، چون هزینه دارند.
